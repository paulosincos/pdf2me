# Prompt: revisar Markdown sem editar

Antes de qualquer execução ou alteração, leia integralmente e siga as [regras comuns](regras-comuns.md), resolvendo o link em relação à pasta deste prompt. Se não conseguir localizar ou ler esse arquivo, aborte sem executar a tarefa nem alterar arquivos e informe o impedimento.

Revise `[ARQUIVO_MARKDOWN]` sem editar nenhum arquivo.

- Verifique se os títulos têm hierarquia coerente e se títulos claramente partidos foram reunidos.
- Verifique se títulos inteiramente em maiúsculas foram padronizados, sem alteração indevida de texto comum.
- Verifique se referências explícitas a páginas receberam, quando possível, um link para a seção correta.
- Confirme que os marcadores `📄 \`Pág. N\`` permanecem sem âncoras adicionadas e que a ordem das páginas, imagens e demais elementos foi preservada.
- Se houver acesso a um diff adequado, verifique se somente o arquivo Markdown de destino foi alterado.

Apresente um resumo breve dos itens verificados e das pendências ou ambiguidades. Não faça alterações; se encontrar um problema, descreva-o para que um dos prompts de edição seja executado separadamente.
